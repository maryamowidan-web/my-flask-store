# my-flask-store
# 🛒 E-Commerce Web Application MVP

A functional, lightweight e-commerce web platform built with **Python (Flask)** and **SQL**. This project serves as a full-stack Minimum Viable Product (MVP) featuring secure user management, product browsing, dynamic cart handling, and automated checkout logic.

---

## ✨ Features

* **User Authentication:** Secure registration, login/logout, password hashing, and session persistence.
* **Product Catalog:** Responsive display of products with detailed views, search, and category filtering.
* **Shopping Cart:** Add, update, and remove items with real-time price and total calculation.
* **Checkout System:** Streamlined order placement logic ready for payment gateway integration.
* **Database Management:** Structured relational database handling users, products, and order histories.
* **Responsive Design:** Mobile-friendly UI designed with standard HTML5, CSS3, and modern layout practices.

---

## 🛠️ Tech Stack

* **Backend:** Python 3, Flask, Jinja2 Templating
* **Database:** SQL / SQLite
* **Frontend:** HTML5, CSS3, JavaScript
* **Deployment & Version Control:** Render, Git/GitHub
